# Propuesta de primer paso

Propongo crear una **entrega piloto del tema 1.1: Topología de los espacios cartesianos** usando la aplicación actual.

## ¿Por qué empezar aquí?

El editor y la exportación ya funcionan; ahora conviene validar que resuelven una necesidad real del curso. Una entrega concreta permitirá descubrir carencias del formato antes de añadir funciones generales que quizá no sean necesarias.

Además, este piloto conecta directamente con las reglas del curso: las preguntas pre-clase deben estar redactadas con claridad y las actividades de fin de semana deben pasarlas en limpio, corregirlas y argumentarlas en LaTeX.

## Resultado esperado

Preparar un ejemplo que contenga:

1. los datos de la entrega (curso, docente, fecha y tema);
2. una pregunta pre-clase corregida y una respuesta explicada;
3. una definición o propiedad;
4. un ejemplo;
5. un ejercicio con solución;
6. referencias consultadas;
7. el archivo `.tex` producido por la aplicación.

## Criterio para dar el paso por terminado

La entrega debe poder crearse solo con teclado, exportarse sin editar manualmente el `.tex` y conservar una estructura comprensible. Si aparece una limitación, añadiremos únicamente el cambio mínimo necesario; por ejemplo, primero intentaremos representar las referencias con un bloque de texto antes de crear un tipo de bloque nuevo.
